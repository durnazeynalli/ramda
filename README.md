# Ramda

A static webpage project built using semantic HTML5 and custom CSS styling.

## Overview

This repository contains a frontend webpage implementation (`hw1.html`) styled with a dedicated stylesheet (`css/hw1.css`) and local image assets (`images/image.PNG`).

## Tech Stack

- **HTML5**: Webpage structure and content
- **CSS3**: Layout and custom styling

## Project Structure

```
ramda/
├── css/
│   └── hw1.css       # Custom stylesheet
├── images/
│   └── image.PNG     # Project visual asset
├── hw1.html          # Main HTML markup
└── README.md
```

## Getting Started

No build tools, package managers, or local dependencies are required.

1. Clone the repository:
   ```bash
   git clone https://github.com/durnazeynalli/ramda.git
   cd ramda
   ```
2. Open `hw1.html` directly in your web browser of choice, or use a local development server such as VS Code's Live Server extension:
   ```bash
   # Optional: using python's built-in server
   python3 -m http.server 8000
   ```
3. Navigate to `http://localhost:8000/hw1.html` if running via a local server.
